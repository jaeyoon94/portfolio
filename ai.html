AI 활용

PM 업무에서 AI에 맡길 범위를 정하고, 결과를 원본과 대조해 검증하는 방식을 정리했습니다.

맡길 작업과 검토 기준부터 정합니다

규칙을 설명하고 결과를 확인할 수 있는 업무에 AI를 적용합니다.
목적과 처리 기준은 PM이 정하고, 검토한 결과를 업무에 반영합니다.

반복 작업을 맡기고 결과를 확인하는 순서

  1. Work Problem반복되는 업무 확인
  2. AI FitAI 적용 여부 판단
  3. Context목적·자료·규칙 정리
  4. Execution정한 범위의 처리·구현
  5. Validation원자료·조건과 대조
  6. Workflow검토 후 업무에 반영
  7. Human Decision우선순위·일정·책임

규칙과 결과를 확인할 수 있는가

같은 정보를 옮기거나 정리하는 일이 반복되는지 먼저 봅니다.
입력과 기대 결과, 처리 규칙을 설명할 수 있는지 확인합니다.

적합하면 · AI 작업으로 분리
반복 규칙이 분명하고 결과와 오류를 확인할 수 있다면, 맡길 작업의 범위를 정합니다.
적합하지 않으면 · 기존 방식으로 처리
규칙이 불분명하거나 결과를 검증할 수 없다면, 기존 절차를 유지하거나 사람이 직접 처리합니다.
자동 처리
규칙에 따른 반복 데이터 정리·동기화·계산
구현 보조
업무 로직 정리, 구현 방향 구체화, 코드 작성과 수정
사람의 판단
처리 대상과 규칙 결정, 우선순위·일정·리스크 판단

명령과 함께 업무 조건을 제공합니다

처리할 자료와 규칙, 필요한 결과를 함께 전달합니다.
빠진 조건이 있으면 실행 전에 보완합니다.

목적과 원자료
어떤 업무를 처리할지, 어떤 문서와 데이터를 기준으로 삼을지 정합니다.
규칙과 제약
처리 범위, 지켜야 할 조건, 예외를 구분합니다.
기대 결과와 확인 기준
결과 형태와 원자료에 대조할 항목을 정합니다.

정한 범위의 처리와 구현을 요청

ChatGPT로 업무 로직과 구현 방향을 구체화하고, Claude·Claude Code로 구현과 수정을 보조받았습니다.
최근에는 Codex로 업무 공간과 프로젝트 관리 게임을 개발하고 있습니다.
도구가 필요하면 요구사항을 기능으로 정리하고 실행·검증·수정을 반복합니다.

실행 결과를 원본과 대조합니다

원자료와 업무 조건, 처리 규칙을 대조한 뒤 사용할지 정합니다.

원자료와 대조
항목과 값이 맞는지, 누락되거나 새로 생긴 내용은 없는지 확인합니다.
업무 조건 확인
목적과 범위에 맞는지, 필요한 예외가 반영됐는지 봅니다.
처리 규칙 확인
원한 동작과 실제 결과가 맞는지, 업무에서 실행할 수 있는지 확인합니다.
사용
확인한 기준에 맞으면 업무에 반영
수정
자료·제약·규칙을 보완한 뒤 다시 확인
사용하지 않음
검증할 수 없거나 업무 조건을 벗어나면 제외
수정이 필요하면 맥락과 규칙부터 다시 확인 ↶

검토한 정보를 일정과 작업 확인에 사용합니다

확인한 관리 정보를 일정과 작업 검토에 활용합니다.
반복해서 쓸 작업은 처리 기준과 예외를 남겨, 다음 실행에서도 결과를 비교할 수 있도록 합니다.

Codex · 개인 프로젝트 · 개발 중

업무 공간과 프로젝트 관리 게임 개발

개발·PMO·퍼블리싱·경영 조직을 가상 오피스에 배치하고, 이동하며 조직 정보를 확인하는 웹게임을 만들고 있습니다.
공간과 조직, 데이터의 연결 방식을 정리해 Codex에 구현을 요청하고, 실행 결과를 보며 수정했습니다.

조직과 역할을 먼저 정리했습니다

화면에 방을 배치하기 전에 조직과 직책, 직무를 구분했습니다.
이후 공간의 위치가 바뀌어도 데이터 연결이 유지되도록 조직 정보와 화면 배치를 분리했습니다.

1층
개발본부와 PMO
2층
퍼블리싱본부
3층
경영진과 경영지원실

조직마다 고유 ID를 두고, 프로젝트·업무·문서를 연결할 수 있는 데이터 구조를 마련했습니다.
현재 조직 구성과 게임 진행 상태는 각 브라우저에 저장됩니다.

요구사항을 정하고, 실행하면서 고쳤습니다

  1. 요구사항 정리
  2. Codex로 구현
  3. 브라우저에서 확인
  4. 수정하고 재확인
직접 정한 내용
층별 조직 구성, 조직과 직무의 구분, 이동·상호작용 방식과 데이터 연결 기준을 정리했습니다.
구현한 내용
층 이동, 조직 정보 조회, 캐릭터와 가구 배치, 진행 상태 저장을 웹게임에 반영했습니다.
확인하고 수정한 내용
캐릭터 이동과 가구 충돌, 조직 정보 접근, 모바일 조작과 화면 겹침을 확인했습니다.
이동 중 캐릭터 이미지가 끊기는 문제와 안내창 배치도 수정했습니다.

한 번의 요청으로 끝내기보다, 실제 화면에서 불편한 점을 찾아 다음 요구사항으로 정리했습니다.
현재도 플레이 흐름과 화면을 다듬고 있습니다.
