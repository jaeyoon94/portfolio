데이터 분석 / BI 시각화

요청한 정보를 지표와 대시보드로 정리

KB국민은행의 차세대 전산시스템 구축 사업인 The K 프로젝트에서 데이터 가공/분석과 Power BI 대시보드 제작을 담당했습니다.

상급 조직의 요청에 맞춰 데이터를 조회하고 Excel로 정리했습니다.
금융/고객 관련 지표를 화면에 구성하고, 개발/데이터 담당자 및 프로젝트 관리자와 협의해 수정했습니다.

데이터 조회부터 화면 수정까지

담당했던 업무를 요청 확인, 데이터 처리, 시각화와 수정 순서로 정리했습니다.

  1. 01

    분석 요청 확인

    분석/보고 목적과 필요한 정보를 확인

  2. 02

    데이터 조회

    사전 작성/튜닝된 SQL 쿼리 사용

  3. 03

    데이터 정제/가공

    Excel로 데이터를 분류하고 분석

  4. 04

    주요 지표 구성

    보고 목적에 맞춰 지표와 비교 기준 정리

  5. 05

    대시보드 제작

    Power BI로 차트와 화면 구성

  6. 06

    피드백 반영

    요청에 따라 지표와 화면 수정

데이터 조회에는 사전 작성/튜닝된 SQL 쿼리를 사용했습니다.

데이터 분석 및 시각화 예시

MySQL/Excel/Power BI로 수행했던 업무를 설명하기 위해 현재 웹 기술로 재구성한 대시보드 예시입니다.

서비스 이용 현황

표시된 지표와 수치는 실제 프로젝트 데이터가 아닌 가상 데이터입니다.

Power BI 파일이나 임베드 화면이 아닌 웹 시각화 예시입니다.

    담당한 업무

    조회와 분석
    사전 튜닝된 SQL 쿼리로 데이터를 조회하고, Excel에서 데이터를 정제/가공했습니다.
    시스템 운영/성능 데이터를 살피고 분석 요청에 따라 대상을 분류했습니다.
    지표와 화면 구성
    보고 목적에 필요한 금융/고객 지표를 구성하고, Power BI에서 차트와 그래프를 배치했습니다.
    주요 정보를 화면에서 비교할 수 있도록 정리했습니다.
    수정과 유지보수
    요청사항과 피드백에 따라 지표/데이터 구성과 시각화 화면을 수정했습니다.
    개발/데이터 담당자, 프로젝트 관리자와 변경 내용을 협의했습니다.

    화면에 무엇을 보여줄지 먼저 확인했습니다

    같은 데이터라도 보고 목적에 따라 필요한 분류와 비교 기준이 달랐습니다.
    요청한 정보를 먼저 확인하고, 지표와 차트를 구성한 뒤 피드백에 맞춰 수정하는 과정을 경험했습니다.

    데이터를 조회하고 가공하는 일과, 검토자가 화면에서 확인할 수 있도록 정리하는 일을 함께 맡았습니다.
