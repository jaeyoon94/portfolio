VDI 소프트웨어 도입 검증

SK주식회사 C&C / 사내 VDI 업무 환경 검증

사내 소프트웨어 도입 전 검증

회사
SK주식회사 C&C
소속/직책
전략기획담당 / 선임
재직 기간
2020.02 ~ 2021.04

사내 VDI 업무 환경에 도입할 소프트웨어를 검증했습니다.
호환성과 보안 위험성, 시스템 성능/안정성을 살피고 결과를 관련 조직과 공유했습니다.

검증부터 유관부서 협의까지

사내 VDI에 도입할 소프트웨어의 호환성과 보안 위험성, 성능/안정성을 검토했습니다.
결과를 정리해 보고하고 사내 IT/보안 조직과 위험 요소와 대응 방향을 협의했습니다.

  1. 01

    검증 대상 확인

    도입할 소프트웨어와 사용 환경 확인

  2. 02

    호환성/보안/안정성 검증

    VDI에서 동작과 위험 요소 검토

  3. 03

    결과 정리와 보고

    확인한 내용과 검증 결과 보고

  4. 04

    유관부서 협의

    IT/보안 조직과 위험 요소 및 대응 방향 공유

주요 검토 영역

호환성
VDI 환경에서 소프트웨어 동작 확인
보안 위험성
도입 전 검토가 필요한 위험 요소 정리
성능/안정성
시스템 성능과 안정성 검토

도입 전에 확인할 위험 요소를 정리하고, 검증 결과를 관련 조직이 함께 확인할 수 있도록 공유했습니다.

검증 결과와 대응 방향 공유

확인된 위험 요소를 정리해 보고하고, 사내 IT/보안 조직과 공유했습니다.
유관부서와 검토 내용을 확인하며 대응 방향을 협의했습니다.
