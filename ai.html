AI & Automation

AI 활용

PM 업무에서 AI 적용 범위와 검증 기준을 정하는 방식.

맡길 작업과 검토 기준부터 정합니다.

규칙을 설명하고 결과를 확인할 수 있는 업무에 AI를 적용합니다. 목적과 처리 기준은 PM이 정하고, 검토한 결과를 업무에 반영합니다.

업무 문제에서 PM 판단까지

  1. Work Problem반복되는 업무 확인
  2. AI FitAI 적용 여부 판단
  3. Context목적·자료·규칙 정리
  4. Execution정한 범위의 처리·구현
  5. Validation원자료·조건과 대조
  6. Workflow검토 후 업무에 반영
  7. Human Decision우선순위·일정·책임

AI Fit

규칙과 결과를
확인할 수 있는가

같은 정보를 옮기거나 정리하는 일이 반복되는지 먼저 봅니다. 입력과 기대 결과, 처리 규칙을 설명할 수 있는지 확인합니다.

적합하면 · AI 작업으로 분리
반복 규칙이 분명하고 결과와 오류를 확인할 수 있다면, 맡길 작업의 범위를 정합니다.
적합하지 않으면 · 기존 방식으로 처리
규칙이 불분명하거나 결과를 검증할 수 없다면, 기존 절차를 유지하거나 사람이 직접 처리합니다.
자동 처리
규칙에 따른 반복 데이터 정리·동기화·계산
구현 보조
업무 로직 정리, 구현 방향 구체화, 코드 작성과 수정
사람의 판단
처리 대상과 규칙 결정, 우선순위·일정·리스크 판단

Context

명령과 함께
업무 조건을 제공합니다.

처리할 자료와 규칙, 필요한 결과를 구분해 요청합니다. AI가 임의로 채울 부분을 줄이기 위한 준비입니다.

목적과 원자료
어떤 업무를 처리할지, 어떤 문서와 데이터를 기준으로 삼을지 정합니다.
규칙과 제약
처리 범위, 지켜야 할 조건, 예외를 구분합니다.
기대 결과와 확인 기준
결과 형태와 원자료에 대조할 항목을 정합니다.

정한 범위의 처리와 구현을 요청

ChatGPT로 업무 로직과 구현 방향을 구체화하고, Claude·Claude Code로 구현과 수정을 보조받았습니다. 도구가 필요하면 요구사항을 기능으로 정리하고 실행·검증·수정을 반복합니다.

Validation

결과는 검토할 초안입니다.

원자료와 업무 조건, 처리 규칙을 대조한 뒤 사용할지 정합니다.

원자료와 대조
항목과 값이 맞는지, 누락되거나 새로 생긴 내용은 없는지 확인합니다.
업무 조건 확인
목적과 범위에 맞는지, 필요한 예외가 반영됐는지 봅니다.
처리 규칙 확인
원한 동작과 실제 결과가 맞는지, 업무에서 실행할 수 있는지 확인합니다.
사용
확인한 기준에 맞으면 업무에 반영
수정
자료·제약·규칙을 보완한 뒤 다시 확인
사용하지 않음
검증할 수 없거나 업무 조건을 벗어나면 제외
수정이 필요하면 맥락과 규칙부터 다시 확인 ↶

Workflow

검토한 결과를
다음 업무로 연결

확인한 관리 정보를 일정과 작업 검토에 활용합니다. 반복해서 쓸 작업은 처리 기준과 예외를 남겨, 다음 실행에서도 결과를 비교할 수 있도록 합니다.

적용 기준은 기존 자동화·업무 데이터 검증 경험을 바탕으로 정리했습니다.
