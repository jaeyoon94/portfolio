Jira 사용 경험과 자체 관리 데이터의 구조화·시각화를 살펴보는 신규 구현 사례입니다.

시연용 가상 데이터 · 아래 수치·일정·담당자는 실제 프로젝트 성과가 아닙니다.
Jira API에 연결된 화면이 아니며, 자체 대시보드를 과거 실무에서 운영했다는 의미도 아닙니다.

프로젝트별 집계

Epic별 완료율

업무 상태 분포

일정 확인

미완료 작업을 종료일 순으로 표시합니다.
시작일과 종료일은 계획 일정이며 실제 완료일은 아닙니다.

    리스크 확인

    차단, 기한 경과, 7일 이내 마감 작업을 확인 대상으로 묶습니다.
    실제 프로젝트의 리스크 등급을 뜻하지 않습니다.

      CSV 업로드 · 검증 및 자동 집계

      UTF-8 CSV · 최대 1 MB / 5,000행.
      선택한 탭의 프로젝트만 허용하며, 전체 파일이 유효할 때 해당 탭의 데이터를 교체합니다.
      파일은 브라우저에서만 처리하며 저장·전송하지 않습니다.
      새로고침하면 데모로 돌아갑니다.

      필수 열: id, project, group, title, owner, status, start, due
      status: todo / doing / done / blocked · 날짜: YYYY-MM-DD · ID 중복 및 시작일·종료일 역전은 허용하지 않습니다.

      업로드 대기 중

      작업과 일정

      완료율 = 완료 건수 ÷ 전체 건수.
      지연 = 기준일보다 종료일이 빠른 미완료 작업.
      차단 = blocked 상태.
      날짜는 달력 날짜 기준입니다.
